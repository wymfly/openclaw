# Backend Gap Ledger

Baseline: `0f17c40ca7`

Use this ledger for Go backend/API/projection gaps discovered while restoring old Control panel workflows. Gateway API remains the source of truth. Old Next Deck behavior is reference evidence only when the Gateway/source capability exists.

Decision values:

- `fix-go`: Gateway/source supports the workflow and Go lacks or misprojects it.
- `adapt-ui`: Go already exposes enough data but the Vite UI must adapt shape or interaction.
- `unavailable`: Gateway/source does not support the old workflow; render an explicit unavailable state.
- `defer-integration`: browser-only evidence remains for the post-merge integration pass.

# Cross-Panel Consistency Checklist

Update this checklist during implementation. This worktree does not need Playwright screenshots, but it must produce code-level evidence that Observe panels use consistent interaction and state semantics.

Status values:

- `pending`
- `passed`: implementation evidence exists and matches the planned semantics.
- `intentionally-local`: repeated structure remains panel-local with a short reason.
- `deferred-to-integration`: allowed only for Playwright/browser screenshot evidence.

Every non-`pending` cell must include a short evidence note or file reference.
If a panel has no panel-level filter, the filter cell still must be non-`pending`, for example `passed: no panel-level filters by design`.

Shared primitive rule:

- Start panel-local.
- Extract Observe-local only after a second panel uses the same stable contract.
- Do not add shell-level shared primitives in this worktree.
- If shell-level reuse becomes necessary, create a separate shared-baseline patch before consuming it here.

Integration branch blocker:

- Playwright/browser screenshots are deferred, but final OpenSpec closure is blocked until the merged local integration branch passes the Observe screenshot matrix in `implementation-plan.md`.

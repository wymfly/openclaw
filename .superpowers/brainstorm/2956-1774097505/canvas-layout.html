A. 左右分栏

Chat 左侧，Canvas 右侧，类似 IDE 编辑器 + 预览。Canvas 激活时自动滑出，隐藏时收回。

优势

  • 同时看到对话和 Canvas
  • 不中断聊天流
  • 与 iOS/macOS 的独立窗口体验对应

劣势

  • 小屏幕下两边都很窄
  • 需要处理响应式布局

B. 弹出式叠加层

Canvas 作为浮层覆盖在 Chat 上方，类似 Modal 但可拖拽调整大小。关闭后回到 Chat。

优势

  • Canvas 获得最大渲染空间
  • 视觉焦点集中
  • 不影响 Chat 布局

劣势

  • 无法同时看对话和 Canvas
  • 频繁切换可能打断工作流

C. 内嵌式 + 可展开

Canvas 默认以卡片形式内嵌在聊天流中（消息之间），点击"展开"可全屏查看。交互在内嵌卡片中直接完成。

优势

  • Canvas 是对话的一部分，上下文自然
  • 小 Canvas 不占空间
  • 可展开获得完整体验

劣势

  • 内嵌尺寸受限
  • 复杂 Canvas 内容在小卡片中体验差
  • 实现复杂（iframe 在滚动列表中）

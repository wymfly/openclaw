交互行为总结

  • 自动展开 — Agent 推送 A2UI 内容时，Canvas 面板自动滑出
  • 手动收起 — 点击 › 按钮或拖到最右收起，Chat 恢复全宽
  • 手动展开 — 点击收起态的 ‹ 按钮重新展开
  • 可拖拽分割线 — 自由调节 Chat / Canvas 宽度比例
  • Debug 模式 — 点击 Debug 按钮，底部滑出调试面板（Messages / Tree 两个 Tab）
  • 自动隐藏 — Agent 发送 canvas.hide 或 A2UI reset 时，面板自动收起

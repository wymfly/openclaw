Module Boundaries & Rules
server/ — 服务端基础设施
• 进程级单例，Next.js 启动时初始化
• 持有 Gateway WS 连接
• 管理 SQLite + EventBus
• 不含业务逻辑，只做连接/存储/广播
src/app/api/ — API 契约层
• 每个路由文件 < 100 行
• 只做参数校验 → 调用 lib → 返回响应
• claw-platform 的封装入口
src/lib/ — 业务逻辑层
• 纯函数优先，可测试
• 每个文件 < 500 行
• 移植模块保持原始接口
• 新增模块遵循同样约束
src/stores/ — 状态管理
• 多 Zustand slice，禁止单体 store
• 每个 slice < 200 行
• subscribeWithSelector 中间件
src/components/panels/ — UI 面板
• 每个面板一个子目录
• 入口组件 + 子组件拆分
• 每个文件 < 500 行
• shadcn/ui 基础组件
Hard Rules
✅ 每个文件 < 500 LOC
✅ 每个 store slice < 200 LOC
✅ 每个 API route < 100 LOC
✅ 零 any，strict TypeScript
✅ 中英双语所有 UI 文本
❌ 禁止单体 store
❌ 禁止直连 Gateway（必须经 server 中转）

Core Design: Effective Config with Inheritance Visibility
  • Inherit / Override badge system NEW — 每个字段旁显示 ↑ default（继承全局默认值）或 ✎ override（代理级覆盖）。用户一眼就知道哪些是自定义的、哪些是从 agents.defaults 继承的。
  • Reset to default NEW — override 字段旁的 ✕ 按钮，点击后移除代理级覆盖，回退到全局默认。
  • Tools Profile Pills NEW — 可视化的 profile 选择器，每个选项显示包含的工具数量。选择后下方即时显示 effective tools 列表。
  • ToolPolicyViz 联动 ENHANCE — 从 tools profile 区域可直接跳转到 ToolPolicyViz tab 查看完整 7 层策略追溯。
  • Save bar with summary NEW — 底部栏显示"N overrides, M inherited"的统计。
Data Flow
  • Read：调用 deck.agents.detail RPC 获取当前代理的 effective config（已合并 defaults + overrides）。同时调用 config.get 获取 raw config 区分哪些字段是 agent-level override。
  • Write：通过 config.patch RPC 写入 agents.list[N].{field}。设为 override = 写入值；reset to default = 删除该字段。
  • 无需新 Gateway RPC：完全复用现有的 config.get + config.patch + deck.agents.detail。
Implementation Scope
  • 新增文件：AgentConfigTab.tsx（主组件）、InheritBadge.tsx（复用组件）、ToolProfileSelector.tsx
  • 修改文件：AgentsPanel.tsx（注册新 tab）、deck-agents store（扩展 fetchAgentConfig/saveAgentConfig）
  • 复用组件：ToolPolicyViz（只读，跳转链接）、ChannelEventStreamSection（eventStreams 已有，移入或引用）
  • Gateway API：无新增，复用 deck.agents.detail + config.get + config.patch

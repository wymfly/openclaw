Design Decisions
  • Section Intro Card NEW — 每个顶级 section 顶部显示一段概述 + docs 链接。内容来源：dashboard 侧维护一份 section → {title, description, docsUrl} 的静态映射（~15 个 section），不依赖 schema。
  • Field Help Popover NEW — 字段名旁的 ? 图标，hover 显示 uiHints.help 内容。825 个字段已有高质量描述，直接使用，无额外维护。
  • Default Value Hint NEW — 字段名下方灰色提示 "default: xxx"，来源于 schema.default。让用户知道不填时的系统行为。
  • Group-based Layout ENHANCE — 利用 uiHints.group（26 个预定义分组）对字段分组，替代当前的扁平列表。每个分组有标题。
  • Advanced Collapse NEW — 带 uiHints.tags 中 "advanced" 标签的字段默认折叠。SectionNav 底部显示 "N advanced fields hidden"。
  • Docs Deep Link NEW — Section intro card 和 help popover 中的文档链接。映射表：section → docs.openclaw.ai URL（静态，dashboard 侧维护）。
  • SchemaForm 集成高级字段 ENHANCE — 已有的 PasswordField / RecordField / UnionField / TypedArrayField 组件集成到主 SchemaForm 的 switch 分支中。当前 schema-parser 已解析出 sensitive / variants / valueSchema / itemSchema 字段，只需在 SchemaForm 中分发。
  • SectionNav 增强 ENHANCE — 显示图标、字段数量计数、advanced 折叠提示。KNOWN_SECTIONS 映射扩展为包含 icon + description。
Implementation Scope
  • 修改文件：ConfigPanel.tsx, SchemaForm.tsx, SectionNav.tsx, schema-parser.ts
  • 新增文件：SectionIntroCard.tsx, FieldHelpPopover.tsx, section-metadata.ts（section → intro/docs 映射）
  • 数据依赖：Gateway 的 config.schema RPC 已返回 uiHints（label/help/tags/group/placeholder/sensitive），无需后端改动
  • i18n：section intro 文字需要 zh.json / en.json 双语维护；field help 来自 schema，已是英文

# WeCom Document Tool Support Matrix

This matrix is the contract authority for the enhanced WeCom document surfaces.
It intentionally compares the local direct `wecom_doc` tool with the Tencent
official WeCom OpenClaw plugin reference and the enterprise WeCom API.

## Authorities

- Official Tencent WeCom plugin reference: `vendor/wecom-openclaw-plugin`
- Official reference remote: `https://github.com/WecomTeam/wecom-openclaw-plugin.git`
- Official reference commit used for this matrix: `7e278be feat: support multimodal data for smartsheet`
- Live official doc MCP schema snapshot:
  `extensions/wecom/docs/official-mcp-doc-tools-2026-05-09.json`
  (`tools/list`, 20 tools, captured from the deployed `default` WeCom bot-ws
  account)
- Excluded reference: `vendor/OpenClaw-Wechat` is a WeChat plugin, not a WeCom authority.
- Official API anchors checked during proposal review:
  - `https://developer.work.weixin.qq.com/document/path/99907` - smart-table add records, embeds `/cgi-bin/wedoc/smartsheet/add_records`
  - `https://developer.work.weixin.qq.com/document/path/99915` - smart-table get records
  - `https://developer.work.weixin.qq.com/document/path/99908` - smart-table delete records, embeds `/cgi-bin/wedoc/smartsheet/delete_records`
  - `https://developer.work.weixin.qq.com/document/path/99914` - smart-table get fields

## Tier And Public Status

| Tier                      | Meaning                                                                                                              |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `official-aligned`        | Matches Tencent official plugin skills/MCP references or a documented enterprise WeCom API endpoint shape.           |
| `live-verified-extension` | Local extension beyond the official plugin skill surface with real WeCom CSV evidence or direct deployment evidence. |
| `compat-hidden`           | Runtime may still handle it for stale sessions, but it is not an Agent-visible contract.                             |
| `unsupported`             | Known non-endpoint, wrong surface, or intentionally not callable through direct `wecom_doc`.                         |

`Public=yes` means the action is allowed in the direct `wecom_doc` public schema.
`Public=no` means it must not be exposed to the Agent as a direct `wecom_doc` action.
`Public=mcp` means the method is official on `wecom_mcp`, not a direct `wecom_doc` action.

## Default And Description Policy

- Empty optional arrays must be omitted from outgoing requests unless the official API explicitly requires them. This is especially important for `field_titles`, `field_ids`, `record_ids`, and `sort`.
- Direct `wecom_doc` can expose local extensions only when this matrix lists `Public=yes` and the tier is not `unsupported`.
- `wecom_mcp` skills should follow Tencent official plugin wording unless a local interceptor is explicitly listed in `extensions/wecom/docs/upstream-porting.md`.
- Do not describe `smartsheet_add_external_records` or `smartsheet_update_external_records` as direct actions. They are Webhook fallback concepts with a different request shape.

# Example — PDF summary

## User request

“请总结这个 PDF，告诉我这份方案的目的、关键结论和风险。”

## Input type

- PDF

## Recommended method

1. Reuse platform PDF extraction if already good enough
2. Preserve document section structure
3. Summarize purpose before details
4. Keep dates, totals, owners, and risks
5. Mention if the PDF appears scanned or partially unreadable

## Preferred output

- short human-readable summary
- bullet list of key conclusions
- bullet list of risks / caveats

# Example — image OCR cleanup

## User request

“把这张白板照片里的内容识别出来，并整理成更清晰的结构。”

## Input type

- photographed document / whiteboard image

## Recommended method

1. OCR the text content
2. Preserve uncertainty where handwriting or blur makes text unclear
3. Reorganize into headings / bullets / numbered items
4. Keep names, numbers, dates, and action items verbatim when visible

## Preferred output

- clean human-readable outline
- short note for unreadable or uncertain fragments

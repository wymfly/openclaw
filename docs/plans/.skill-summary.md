# Skill 摘要（由 orchestrator 从完整 Skill 提取）

## frontend-design 关键约束

- 不使用默认 AI 审美（避免 Inter/Roboto/Arial、紫灰渐变、cookie-cutter 布局）
- 字体选择独特有记忆点，配对 display + body font
- CSS variables 保持一致性，主色调+锐利强调色
- 动画优先 CSS-only，React 用 Motion library
- 空间构成：允许不对称、重叠、grid-breaking
- 背景和视觉细节要创造氛围和深度
- 匹配实现复杂度与美学愿景

## TDD 关键约束

- NO PRODUCTION CODE WITHOUT A FAILING TEST FIRST
- Red-Green-Refactor 三步不可跳步
- 每个测试验证一个行为
- 测试名清晰描述行为
- mock 只在真正需要隔离时使用
- 运行测试确认失败 → 写最小实现 → 确认通过 → 重构
- 写了代码没先写测试？删掉重来

## ui-ux-pro-max 关键约束

- 组件遵循 Design Baseline（shadcn/ui + Tailwind CSS variables）
- 间距系统：4px 基准网格
- 颜色来源：CSS variables（--accent, --bg-primary 等），不硬编码
- 深色模式：所有组件必须在 dark/light 下正常显示
- 响应式断点：mobile(<768) / tablet(768-1023) / desktop(≥1024)
- 无障碍：交互元素有 aria-label，键盘可达

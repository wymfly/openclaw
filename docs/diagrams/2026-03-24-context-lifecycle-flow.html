Context Lifecycle Flow

Session resolution → context budget → pruning → compaction → model inference 
flowchart TD
    START([Message Arrives]) --> RESOLVE_KEY["Parse Session Key
agent:id:channel:rest"]

    RESOLVE_KEY --> LOAD_SESSION{"Session exists
& fresh?"}
    LOAD_SESSION -->|"Yes"| REUSE["Reuse sessionId
Load .jsonl history"]
    LOAD_SESSION -->|"No (stale/new)"| CREATE["Generate new UUID
Create .jsonl file"]

    REUSE --> HISTORY_LIMIT
    CREATE --> HISTORY_LIMIT

    HISTORY_LIMIT["Apply History Limit
Keep last N user turns"]

    HISTORY_LIMIT --> RESOLVE_CTX["Resolve Context Window
model registry → config → default"]

    RESOLVE_CTX --> GUARD{"Context Guard
tokens >= 16K?"}
    GUARD -->|"< 16K"| BLOCKED([Block Execution])
    GUARD -->|">= 16K"| CHECK_BUDGET

    CHECK_BUDGET{"History fits
in budget?"}

    CHECK_BUDGET -->|"Yes"| PRUNE_CHECK
    CHECK_BUDGET -->|"No (overflow)"| COMPACT

    PRUNE_CHECK{"Cache-TTL
pruning enabled?"}
    PRUNE_CHECK -->|"Yes"| PRUNE["Prune Old Tool Results
Soft: keep 1.5K head+tail
Hard: replace with placeholder"]
    PRUNE_CHECK -->|"No"| RUN_AGENT

    PRUNE --> RUN_AGENT

    COMPACT["Compaction
1. Strip tool result details
2. Split history by token share
3. LLM summarization per chunk
4. Preserve all opaque IDs"]

    COMPACT --> COMPACT_OK{"Compaction
succeeded?"}
    COMPACT_OK -->|"Yes"| RUN_AGENT
    COMPACT_OK -->|"No"| FALLBACK["Try Fallback Model
or return error"]

    RUN_AGENT["Run Agent
PI Embedded Runner
Model inference + tools"]

    RUN_AGENT --> OVERFLOW{"Context overflow
during run?"}
    OVERFLOW -->|"Yes"| COMPACT
    OVERFLOW -->|"No"| PERSIST

    PERSIST["Persist State
1. Append to .jsonl
2. Update SessionEntry
3. Track token usage
4. compactionCount++"]

    PERSIST --> DONE([Response Delivered])
    FALLBACK --> DONE

Each agent turn: parse session key → load or create session → apply history limit → resolve context window → guard check (block if <16K) → optionally prune old tool results (cache-TTL) → if overflow, compact via LLM summarization → run agent → if overflow mid-run, compact and retry → persist state to JSONL + update SessionEntry.

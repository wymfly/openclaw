Inbound messages are routed to agents via binding rules (7 priority tiers). Agents can spawn subagents through 5 validation gates. Child agents run independently with inherited workspace, announce results back via push. Parent can steer (redirect) or kill children. Registry tracks lifecycle; run-mode sessions auto-cleanup after completion.

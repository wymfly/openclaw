Attachments

Subagent files in ~/.openclaw/attachments/{UUID}/. Max 5MB total, 50 files, 1MB each

Session Key identifies conversations (agent + channel + peer + thread). SessionEntry stores per-session state (model overrides, token usage, compaction count). Context window is resolved from model registry with configurable caps. When context pressure builds: first try lightweight pruning (tool result TTL), then full compaction (LLM summarization). All conversation history persists as JSONL files under ~/.openclaw/agents/.

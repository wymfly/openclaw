All channels are plugins with the same ChannelPlugin interface. Plugin SDK provides helpers (defineChannelPluginEntry, createChatChannelPlugin). At gateway startup, PluginRuntime is injected giving plugins access to config, media, events, and tools APIs. Plugins can additionally provide skills, hooks, agent tools, and cron jobs.

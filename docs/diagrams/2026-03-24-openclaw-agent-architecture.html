Messages flow top-down: Clients/Channels → Gateway RPC → Session routing → Agent resolution (config, tools, skills, model) → Runtime execution (PI agent, subagents, ACP) → AI providers & storage. Each agent has isolated config, workspace, and session state. Subagents inherit parent context with optional overrides.

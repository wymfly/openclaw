Key Gaps & Recommendations

HIGH

Context Inspector (compaction + pruning visibility)

Users cannot debug "why did the agent forget X". Need: compaction timeline (when + tokensBefore/After + summary preview), pruning state indicators, context composition pie chart (system prompt vs history vs tool results).

HIGH

Identity Management Panel

Backend deck.identity.* API is ready but has no UI. Critical for multi-channel deployments where users interact via Telegram + WeCom and need unified identity.

MED

Usage Timeseries API + Chart

Frontend has disabled fetchTimeseries — backend aggregation API needed. Without it, users can't track cost trends or detect usage anomalies over time.

MED

Thread Browser Panel

Backend deck.threads.list exists but no UI. Users managing Slack/Discord threads have no visibility into thread hierarchy from the dashboard.

MED

Sandbox & Thinking Controls

Agent detail has sandbox/thinking data fields but no interactive controls. Users must edit YAML config to change these settings.

Audit of 24 Deck Dashboard panels against 6 core backend modules. Overall 92% coverage. Strongest: Chat, Monitor, Routing, Subagents. Weakest: Context observability (compaction/pruning invisible), Identity management (API exists, no UI). Priority recommendations: Context Inspector panel, Identity panel, Usage timeseries backend API.

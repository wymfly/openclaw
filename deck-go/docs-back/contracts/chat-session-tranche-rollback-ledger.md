# Chat / Session Tranche Rollback Ledger

This ledger complements the row-level ownership ledger by pinning rollback expectations per Phase 3 tranche.

## Tranche Rollback Ledger

| Tranche                                 | Workflow rows                                                                                              | Exit gate                                                                                                                                                                                                           | Rollback trigger                                                                                                                                                  | Rollback action                                                                                            |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 3A — Browse / Select / Read             | Agent tabs / agent selection; Session list load; Session preview overlay; Chat snapshot; Chat history seam | All browse/select/read rows are `deck-go-owned` or explicitly bounded `adapter-window`; shell browse/read path remains parity-or-better                                                                             | browse/select/read regress, preview/snapshot mismatch, transcript browse bootstrap instability                                                                    | revert affected workflow rows to the legacy-owned path until the deck-go row is corrected                  |
| 3B — Send / Stream / Abort / Continuity | Send action; Abort action; Session create; Session event subscribe; Global SSE stream                      | transcript continuity proven; tool/result projection continuity proven; live conversation path remains parity-or-better                                                                                             | send/abort failure, replay/reconnect holes, ordering regression, `projection.gap` misbehavior, tool/result projection breakage                                    | revert affected workflow rows to the legacy-owned live conversation path and block tranche completion      |
| 3C — Operational Intelligence           | Status / SSE / exception banners; Tool progress / run status surface; Approval surface                     | status/error behavior remains discoverable; tool progress/run status is real and actionable; approval flow is real and actionable                                                                                   | placeholder-only behavior persists, approval actionability regresses, operator status becomes misleading                                                          | revert affected operator-surface rows to the legacy-owned path until the migrated surface is real          |
| 3D — Auxiliary Workspace                | Transcript search / filter; Artifact surface; Canvas / A2UI surface; Session-scoped configuration          | search/filter remains parity-or-better; artifact/canvas entries and current interactions remain coherent; session-config bar stays reachable and preserves current writes through explicit adapter-window semantics | search/filter regression, artifact/canvas interaction regression, config writes (`fastMode`, `thinkingLevel`, `responseUsage`, `sendPolicy`) stop being preserved | revert affected rows to legacy-owned/adapter-window path and keep session-config writes on the legacy seam |

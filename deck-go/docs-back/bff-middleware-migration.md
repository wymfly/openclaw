# Deck Go BFF Middleware Migration

Scope: PR-17 migrates only `gateway-rpc-proxy` endpoints from `deck-go/docs/fe-endpoint-classification.md` to the generated Gateway typed client.

| Middleware Concern           | Existing BFF Behavior                                                                       | Migration Target                                                                                                                                                   | Notes                                                                                                      |
| ---------------------------- | ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| Deck access token            | `deckFetch` injects `x-deck-token` from stored Deck auth state or an explicit token option. | `createDeckGatewayTransport` still calls `deckFetch` and passes `{ token: accessToken }` when a typed caller supplies an access token.                             | BFF control-plane and binary/SSE routes continue to use `deckFetch` / `deckStream` unchanged.              |
| Gateway authorization header | Legacy proxy routes could receive caller auth headers before forwarding.                    | `createDeckGatewayTransport` injects `Authorization: Bearer <accessToken>` when `accessToken` is provided.                                                         | The generated `createGatewayClient(request)` signature is unchanged; auth is caller-side wrapper behavior. |
| Request tracing              | Legacy proxy paths used request ids from HTTP headers or server-generated ids.              | `createDeckGatewayTransport` injects `X-Request-Id` into every typed RPC POST and the backend echoes it in the Gateway RPC envelope.                               | Callers may provide a stable `requestId`; otherwise the wrapper generates one.                             |
| Method allowlist             | Legacy BFF routes exposed one hardcoded method per endpoint.                                | `/api/v1/runtimes/{runtimeId}/gateway/rpc` accepts only generated typed Gateway methods from `generated.TypedMethodNames`.                                         | D12 untyped exceptions remain blocked from the FE typed transport.                                         |
| Timeout                      | Legacy BFF route handlers owned fixed or route-specific timeouts.                           | The generated typed client passes `options.timeoutMs`; `createDeckGatewayTransport` serializes it into the RPC body; the Go handler applies `context.WithTimeout`. | Callers without explicit timeouts keep request-context cancellation.                                       |
| Error envelope               | Legacy proxy routes returned route-specific JSON errors.                                    | `createDeckGatewayTransport` parses Gateway envelopes and throws `GatewayError` with `kind`, `code`, `details`, `requestId`, and `status`.                         | Scope-denied responses remain distinguishable by `error.code === "scope_denied"`.                          |
| Rate limiting                | No frontend-specific per-method limiter exists in the current Deck FE transport.            | No PR-17 migration needed.                                                                                                                                         | Any backend/global limiter remains outside the typed client wrapper.                                       |
| BFF-only validation/shaping  | BFF routes validate local forms, apply defaults, or reshape local projections.              | Not migrated.                                                                                                                                                      | These routes stay Category=`deck-go-bff` in `fe-endpoint-classification.md`.                               |

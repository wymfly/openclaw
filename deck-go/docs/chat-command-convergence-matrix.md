# Chat Command Convergence Matrix

OpenSpec change: `deck-command-convergence-real-e2e`

This matrix is the working inventory for visible Deck Go Chat commands. It is generated from code truth, not from memory:

- Frontend local definitions: `deck-go/frontend-new/src/components/panels/chat/slash-commands.ts`
- Frontend registry/executor: `deck-go/frontend-new/src/lib/command-registry.ts`, `deck-go/frontend-new/src/components/panels/chat/slash-command-executor.ts`
- Gateway discovery authority: `src/gateway/server-methods/deck/commands.ts`
- OpenClaw builtin command truth: `src/auto-reply/commands-registry.shared.ts`
- Deck BFF Chat routes: `deck-go/backend/internal/server/chat.go`

Status values:

- `complete`: backend/OpenClaw path evidence and frontend UI/rendering evidence both exist.
- `degraded`: product path is implemented, but one required signal or real proof is weaker than the spec target.
- `skipped-safe`: code/UI path is reviewed, but real execution is intentionally skipped for safety.
- `handoff-blocked`: source contract, fixture, or product decision is missing.

## Local Shadowing And Collision Policy

Source priority is `plugin < local < builtin < skill` in `SOURCE_PRIORITY`, where lower number wins. Local product commands intentionally shadow Gateway builtins when Deck needs a typed BFF route, durable UI state, or product-specific option set.

| Collision                   | Active command | Displaced path                            | Rationale                                                                                                      |
| --------------------------- | -------------- | ----------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `/help`                     | local          | Gateway builtin `/help`                   | Deck currently exposes frontend-local help; matrix marks it degraded because it omits discovered commands.     |
| `/agents`                   | local          | Gateway builtin `/agents`                 | Deck uses typed `deck.agents.list` via BFF for control UI consistency.                                         |
| `/model`                    | local          | Gateway builtin `/model`                  | Deck patches session DTO and updates context meta without relying only on textual Gateway reply.               |
| `/think`, `/thinking`, `/t` | local          | Gateway builtin aliases                   | Deck uses session patch DTO and narrower product option set.                                                   |
| `/fast`                     | local          | Gateway builtin `/fast`                   | Deck updates `fastMode` context meta through BFF.                                                              |
| `/verbose`, `/v`            | local          | Gateway builtin aliases                   | Deck supports product-specific `full` display state.                                                           |
| `/reasoning`, `/reason`     | local          | Gateway builtin aliases                   | Deck updates session meta and streaming visibility mode.                                                       |
| `/usage`                    | local          | Gateway builtin `/usage`                  | Deck controls response usage display; Gateway `cost` remains product-deferred.                                 |
| `/stop`                     | local          | Gateway builtin `/stop`                   | Deck aborts through `POST /api/chat/abort` and clears streaming state.                                         |
| `/reset`                    | local          | Gateway builtin `/reset`                  | Deck resets through `POST /api/chat/sessions/reset` and clears projection.                                     |
| `/new`                      | local          | Gateway builtin `/new`                    | Deck creates active sessions through typed BFF route.                                                          |
| `/compact`                  | local          | Gateway builtin `/compact`                | Deck must add durable in-flight and final metadata UI around compaction.                                       |
| `/export`                   | local          | Gateway `/export-session` alias `/export` | Deck exports current UI transcript locally; Gateway filesystem export remains available via `/export-session`. |

## Unsafe Or Bounded Real E2E Policy

Real E2E samples must use the isolated real Gateway stack and disposable run-scoped data. The default safe samples are:

- local config: `/t high` or `/usage tokens`;
- local query: `/usage status` or `/agents`;
- local mutation: `/compact` against a disposable session;
- Gateway builtin: `/status`;
- alias: `/id` or `/t high`;
- unknown command: `/definitely-missing-command`;
- skill/plugin: discovery proof, and dispatch only when a harmless fixture exists.

Commands classified as skipped-safe for real execution include shell/process/runtime/config/security/media/destructive commands such as `/bash`, `/restart`, `/kill`, write modes of `/config`/`/mcp`/`/plugins`, `/allowlist`, `/approve`, `/exec`, `/elevated`, and external media commands such as `/tts`.

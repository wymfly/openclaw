# Design Reference Library

> 把"看不见摸不着的设计味道"变成可指认的样板房。

每张卡是一份 self-contained HTML，独立打开就能看到一家公司 design system 的 **视觉气质 + 信息密度 + 交互模式 + 灵魂细节**。

## 怎么用

1. **设计新模块前**：打开 2-3 张卡并排看，告诉 Claude "我要 X 的味道 + Y 的密度"
2. **回答 elicitation 提问时**：作为视觉锚点的真实样本
3. **跟设计师/Claude 对齐时**：直接发卡，比 100 句描述都准

## 每张卡的 5 区结构

1. **顶部气质标签** — 一句话定性
2. **Tokens 速览** — 颜色 / 字体 / 圆角 / 间距实物
3. **典型页面缩略** — CSS 高保真复刻一个代表页
4. **组件样本** — Button / Input / Card / Badge 实物 + 设计意图
5. **交互特征 + 适用场景** — 灵魂细节 + "什么时候选它"

## 加新卡

复制 `_template.html`，改 5 个区的内容即可。卡之间风格要克制，不要让"参考卡本身"也卷进设计——卡是说明书，不是炫技场。

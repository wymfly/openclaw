§ 03

组件样本

每个组件都为"对话流"服务：低视觉重量、强可读性、强调色克制使用。

Buttons

主按钮使用 clay 橘只在"开启动作"时出现（New chat、Send）。次按钮纯白底加细描边，ghost 完全隐身，让文字内容做主角。

Input · 双状态

Reply to Claude…
In a little wine bar at the edge of dusk…

未聚焦时几乎隐形（边框跟背景几乎同色），聚焦时浮上一层 paper 白 + clay 边框 + 3px 软光晕。让"开始打字"成为视觉上的小仪式。

Badge / Tag

Default New Beta

圆角 999（full pill），低对比度。clay 强调橘只用于"新功能"这种值得看一眼的事，不滥用。

嵌套卡片用 linen-2 比主背景略深一点点，靠"色阶"而不是"阴影"建立层级。这是浅色派最克制的做法。

Tooltip

⌘ Enter to send

tooltip 用近黑色 ink-1 反差，给键盘提示留位置。这是页面里**唯一**用深色块的地方。

Avatar / Logo Mark

S

圆形+方形交替使用：圆形给"人"（Claude / user），方形给"产品标"。颜色上 clay 是 Claude 的 signature，黑色给真人。

§ 04

灵魂细节

这些是让人一眼认出"这是 Claude.ai"的 5 个特征。复刻视觉容易，复刻这些难。

A

衬线大标题做页面节拍器

Source Serif 在大字号下展现的笔锋让产品页面像在读杂志，不是在用 SaaS。这一点单凭加几个 padding 学不来。

B

橘色用一次顶十次

整个 UI 真正出现 clay 的地方屈指可数：主 CTA、focus ring、avatar、accent badge。它的力量来自稀缺。

C

对话回合之间的呼吸

turn 之间 36-40px 的纵向间距，比一般产品大得多。这让"思考"在视觉上有位置存在。

D

无阴影，靠色阶分层

linen / linen-2 / linen-3 / paper 四层暖白叠出深度，不靠 shadow。结果是页面看上去更"轻"、更"纸"。

E

composer 的"漂浮卡片"做法

底部输入框是浮在背景上的圆角卡片，自带轻微 shadow。让"打字"区域被视觉提名，不至于淹没在内容流里。

F

键盘提示常驻可见

⌘K、⌘Enter 这些 hotkey 不藏在帮助菜单里，直接出现在 tooltip / input affordance 中。键鼠平衡，但键盘党也照顾到了。

§ 05

什么时候选这个味道

这套设计语言不是万能。下面这两栏告诉你它适合什么、不适合什么。

选 Claude.ai 的味道，当你的产品想被"读"，而不是被"扫"。

适合
  • 对话 / 写作 / 阅读 / 思考 类工具
  • 用户停留时长 > 10 分钟的产品
  • 低频但重要的决策场景（投资、写作、咨询）
  • 愿意"贵一点也要好看"的中高端定位
  • 内容是主角，UI 是配角
不适合
  • 数据密集的 dashboard / 工作管理类
  • 用户每天高频快速操作的场景（< 30 秒一次）
  • 移动端为主的消费产品
  • 需要展现"产品很有数据/很专业"的工具
  • 预算有限、需要快速识别度的 startup MVP
